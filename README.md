### 🛸 Vibe Coding 技术栈

> **Vibe Coding** —— 跟着感觉走，用自然语言描述需求，让 AI 帮你生成代码，尽量减少手动编码。
> 对这种开发方式最友好的技术栈：生态成熟、约定大于配置、AI 训练数据丰富、样板代码少。
